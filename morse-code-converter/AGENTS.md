# AGENTS.md - Morse Code Converter

Single-purpose static tool, built as a **world page**: telegraph desk. Convert text to Morse code and Morse back to text on a telegraph desk: the message is typed on a telegram blank, the Morse appears on the line below and is drawn on a register tape, and Play taps it out through a Web Audio straight key at PARIS timing (5 to 35 wpm, 400 to 1000 Hz) while the sounder lamp flashes and the tape follows. Full alphabet, digits and punctuation, either direction live. Nothing uploaded. Part of the crusher-labs static tools line. Hosted on GitHub Pages at https://tools.muhammadhassaanjaved.com/morse-code-converter/

Workspace rules: `x:\crusher-labs\AGENTS.md`. Global rules: `~/.claude/CLAUDE.md`. Design standard: `x:\crusher-labs\docs\design-language.md` (tools section) and the atlas `x:\crusher-labs\docs\context\tools-theme-atlas.md`.
